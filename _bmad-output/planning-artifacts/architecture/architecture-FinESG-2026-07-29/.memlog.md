- (decision) Working mode: Fast path chosen by user; draft the full spine with [ASSUMPTION] tags rather than coaching elicitation.
- (decision) Stack shape chosen by user: Python API (FastAPI) + React SPA, split services. Rationale: PDF/OCR/MILP/verifier are Python-native; the 19-surface UX spine with editable 12-month tables, PDF bounding-box viewer and WCAG 2.2 AA is React-native. Alternatives weighed and rejected: Next.js full-stack + Python solver service (splits financial logic across two languages), Python monolith + HTMX (cannot carry CMP-05/CMP-06/CMP-07 density), all-TypeScript with highs-js WASM (Vietnamese OCR and an independent verifier in JS is unacceptable risk at six weeks).
- (decision) MILP solver: HiGHS via highspy, chosen by user. Gives deterministic mode, MIP gap, time limit and thread control — exactly the run-provenance fields PRD 4.5.1 requires. Rejected: OR-Tools/SCIP (heavier image, weaker multi-tier ergonomics), PuLP+CBC (slower, weak determinism control, risks NFR-1/NFR-7), Gurobi (commercial licence, cannot ship in a free Docker demo).
- (constraint) HiGHS has no native indicator constraint. PRD FR-17 explicitly permits the big-M fallback provided M is derived from confirmed-data bounds and persisted in the run. The DSCR conditional (h) therefore uses derived big-M, not an indicator.
- (constraint) HiGHS has no native IIS. PRD FR-22 explicitly permits the fallback: a separate diagnostic model with unit-carrying slack variables and published penalties, used only for explanation, never promoted to a Phuong an.
- (decision) PDF extraction: local-only, PyMuPDF for text-layer plus Tesseract vie for scans, chosen by user. Keeps sensitive BCTC data off third-party services per NFR-9/10/11 and the unresolved rights_status in data_inventory.csv. Rejected: PaddleOCR (multi-GB image, slow build), cloud Document AI (conflicts with NFR-11 and the rights review).

- (decision) AD-22 added (high D-03): four independently versioned aggregates with one writing role each — FsDataset/Accountant, ScenarioAndFunding/CFO, ProjectFinance/CFO, ProjectEvidence/ESG.
